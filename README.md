# WoW-F-BussinessClac · 魔兽世界无限 · 制造业冲级价格计算器

基于《魔兽世界：无限》版本配方数据的在线冲级规划工具：导入游戏内 AUC 插件导出的拍卖行价格，
  
按「最新数据 / 中位数」两种口径，结合 NPC 卖店价，计算各制造专业从当前技能冲到目标技能的
  
**成本最优路线**，支持逐配方屏蔽 / 确认采用、材料采购清单、路线保存与同服玩家互相分享。

功能参考 [wowplayer.cc](https://wowplayer.cc/)（WLK 版），**配方数据全部以「无限」版本为准**
  
（来源：[wowforever.wclbox.com 专业库](https://wowforever.wclbox.com/zhuanye)，官方开放 API，客户端版本 1.60.1.70532）。

## 功能一览

| 模块          | 说明                                                                                             |
| ----------- | ---------------------------------------------------------------------------------------------- |
| 多服务器 + 阵营隔离 | 价格按服务器 + **阵营**（联盟/部落/双阵营共用）隔离；同服同阵营玩家导入的价格互享，跨阵营互不可见                                          |
| AUC 价格导入    | CSV 上传 / 粘贴；支持 **AUC 拍卖行导出格式**（带物品等级，同名不同物品自动消歧）、文档格式与物品链接格式；每次导入留痕，可手动补价                      |
| 模板导出        | 按专业生成 AUC 关注清单（`锻造^铜锭^…`），游戏内导入后按清单导出价格，解决「不知道该导哪些物品」                                          |
| 采购清单导出      | 路线算出的材料清单一键生成 AUC 关注清单（`炼金术采购清单^…`），去游戏内按清单导价回填                                                |
| 价格口径        | 每物品可选「最新数据」（默认）或「中位数」                                                                          |
| 拍卖行手续费      | 成品卖拍卖行时收入按**到手价**（成交额扣 5% 手续费）计，材料价=成品价的配方会如实显示为亏 5%                                           |
| 收益保底          | 拍卖行查不到价、或**到手价还不如 NPC 卖店价**时，自动按卖店价计（列表标「按卖店」），绝不会算出比直接卖店更亏的收益                                  |
| 涨点几率        | 默认按 WoW 客户端真实公式 `(灰档−当前技能)/(灰档−黄档)`（橙档 100%）；也可切「固定档位」按私服经验自填橙/黄/绿几率                           |
| 路线计算        | 事件驱动贪心：按技能档位（橙/黄/绿/灰）估算涨点概率，最小化「每技能点净成本」；**同一产品连续制作合并为一段**（档位显示几率区间 100% → 20%）                |
| 物品来源        | 材料自动比价：NPC 购买（卖店价）vs 拍卖行，取低价；**NPC 限量材料（草药等）只认拍卖行**（不限量展示）                                     |
| 成品处置        | 全局默认 + **逐配方覆盖**：配方行直接显示「卖店价 / 拍卖行价」两个价格按钮，点价格即选中该处置（信息展示即操作）；自用不计收入                           |
| 设计图成本       | 拍卖行可购买的设计图（非拾取绑定）按一次性成本计入冲级总成本；掉落获取的图纸可切换为不计                                                   |
| 配方屏蔽        | 原材料无法获取或成品无法出售时，屏蔽该配方或屏蔽该物品（全链路生效）                                                             |
| 确认采用        | 指定必须制作的配方，路线优先排产；**次数默认值分两种**：有 CD 的配方（月布等，列表标 `CD`）默认 1 次，其余默认**不限**（留空即不限，次数用尽才退出路线） |
| 路线分享        | 保存后直接给出可复制链接 `/r/{分享码}`，点开就是整条路线（步骤 + 材料清单）；他人可一键「用我服务器的价格重算」                                        |
| 物品详情        | 悬停物品**图标或名称**都弹**仿游戏内**信息卡：品质色名称、物品等级/ID、绑定、部位（右对齐护甲类型）、护甲值、属性、耐久、需要等级、绿色装备特效、售价（带硬币图标）；底部附本服拍卖行参考价，并注明这条价**多久前导的**、是否超过有效期 |
| 价格有效期        | 计划页顶部与导价页恒定显示「最近一次导入 N 小时前（有效期 24h）」，过期整条红字提醒 + 每个物品卡单独标注；只做提示，不改计算口径（`WOWFC_PRICE_VALID_HOURS` 可调） |
| 导价图文教程      | 新增 `/guide` 页面：6 步把本站模板送进游戏 AUC 再导回价格，每步配图位（没图时显示「拍什么」占位），并列出需要哪些截图 |
| 图标          | 专业 / 配方 / 路线 / 材料清单 / 阵营徽记均显示无限版图标（官方库 CDN，失败回退原版 wowhead）；金钱为金银铜币**矢量图标**（数字在前、图标在后，同游戏）      |
| 数据规模        | 9 个制造专业 · 2150 个配方 · 3979 个物品（2039 个含卖店价、全部带图标）                                                |

## 技术栈

- 后端：Python 3.12 + FastAPI + SQLAlchemy 2.0 + Pydantic v2（SQLite 开发 / PostgreSQL 生产）
- 前端：Vue 3 + TypeScript + Vite + Pinia + Vue Router
- 部署：单容器（后端托管前端构建产物，单端口）或 docker-compose（PostgreSQL）

## AUC 价格导入格式

游戏内 AUC 插件导出 CSV 后，直接在「价格导入」页上传或粘贴（计算参数行的「价格导入」按钮也可直接导，导完自动重算）。支持三种写法（UTF-8 / GBK 自动识别）：

**1. AUC 拍卖行导出**（推荐，表头 `"价格","名称","物品等级","拥有？","可售数量"`）：

```csv
"价格","名称","物品等级","拥有？","可售数量"
115,"劣质火药",5,"",1169
200,"劣质炸药",20,"",61
90,"劣质炸药",10,"",399
```

- 价格列为铜；「物品等级」用于区分**同名不同物品**（如「劣质炸药」物品等级 10 / 20 是两个不同物品，会分别按各自价格入库）；
- 同名物品若导出未带等级列，则同名物品按同一价格入库，可事后在导入页手动微调。

**2. 文档格式**（表头需包含名称列与价格列，列名兼容 `物品名称/名称/item/name`、`单价/价格/price`）：

```csv
物品名称,单价
铜锭,25
秘银锭,1银20铜
铁锭,1金
```

**3. 物品链接格式**（Auctioneer / TSM 等插件常见，按物品 ID 精确匹配，最可靠）：

```csv
|cff1eff00|Hitem:2840:0:0:0:0:0:0:0|h[铜锭]|h|r,25
|cffffffff|Hitem:3575:0:0:0|h[铁锭]|h|r,80
```

也支持无表头两列（名称,价格）。

价格写法支持：纯数字（铜）、`25银`、`1金23银4铜`、`1g23s4c`、`1.5g`（小数金）。
  
仓库内置示例：`backend/data/sample_auc_import.csv`。

未匹配到物品库的名称会在导入结果中列出（该物品在无限版不存在或改了名），不影响其他行入库。
  
单个物品也可以在导入页手动录价。

## 模板导出（AUC 关注清单）

不知道该导哪些物品的价格？在「价格导入」页或「冲级计划」页点**导出模板**：

1. 选专业（可限定技能区间），生成该专业全部配方涉及的物品清单——材料 + 成品 + 设计图，
     
   输出为 AUC 关注清单文本，第一段是清单名，其余用 `^` 分隔：
   ```text
   锻造^中皮^乌木刀^…^铜锭^…^设计图：铜质链甲外衣^…
   ```
2. 游戏内 AUC 的关注清单导入里粘贴该文本；
3. 在拍卖行按清单浏览，导出价格文本（即上面的 AUC 导出格式），回本工具导入。
4. 图文版步骤见站内 **`/guide`**（导价教程）：每步一张图，图片放 `frontend/public/guide/step1.png …step6.png` 即自动显示，
   未放图时页面显示「这张要拍什么」的占位说明。

API：`GET /api/v1/professions/{key}/watchlist`（可选 `from_skill` / `to_skill` 过滤技能区间）。

## 价格有效期（云价格多久前导的）

私服没有实时行情，价格是玩家导的一次快照，所以每条价都带时间戳：

- `GET /api/v1/prices/freshness?server_id=` → 最近一次导入时间、覆盖物品数、已过期物品数；
- `GET /api/v1/items/{id}` → `price_updated_at` / `price_age_hours` / `price_stale` / `price_valid_hours`；
- 计划页「计算参数」下方恒定一行「价格数据 · 最近一次导入 X 小时前（有效期 24 小时）· 覆盖 N 个物品」，
  超期变成红字并额外说明「其中 M 个物品的报价已过期」；导价页同款一行；
- 物品卡底部：「拍卖行 3银 · 2 天前」，过期再补一行红字「⚠ 这条报价已超过 24 小时有效期，建议重新导价」。

阈值 `WOWFC_PRICE_VALID_HOURS`（默认 24）。**只提示不改算法**：过期价格仍参与计算，由用户决定要不要重扫。

## 设计图成本

「无限」版本中大量配方需要先学会设计图（AH 可购买、非拾取绑定）。计算参数行提供：

- **含设计图配方**：是否把设计图配方纳入路线；
- **图纸成本**：`AH 购买计入`（默认）——路线用到该配方时，图纸价格作为**一次性成本**计入总成本
    
  （学会即消耗，不随制作次数增加；图纸无价格时按 0 计并警告）；`掉落不计`——图纸靠掉落获取，不计价。

被屏蔽的设计图物品同样会让对应配方退出计算。

## 计算规则说明

- **涨点几率**（两档模型，界面可切）：
  - **客户端公式**（默认）：WoW 1.12 客户端实际机制（WowWiki 存档 + SkillUpProbability 插件实证）——
      
    橙档（当前技能 < 黄档）100%；黄/绿档 `几率 = (灰档 − 当前技能) / (灰档 − 黄档)`，
      
    即刚变黄仍接近必涨、到绿档时约 50%、向灰档线性衰减至 0。期望制作次数按逐点 `1/几率` 累加。
  - **固定档位**：橙/黄/绿各一个固定几率（界面可填，服务端默认 100%/50%/25%），
      
    适用于服务端自定义了几率的私服，按实际经验调。
- **技能档位**直接取自官方数据库：每配方有「学会（橙）/ 变黄 / 变绿 / 变灰」四个阈值。
- **路线算法**：从当前技能出发，在每个事件点（配方档位变化、新配方解锁、到达目标）重新选择
    
  「每技能点净成本最低」的配方；被「确认采用」的配方优先排产（有用尽次数上限）；被屏蔽的配方/物品不参与。
- **净成本** = 材料花费 − 成品收入；材料自动取 NPC 与拍卖行中的低价。
- **成品收入** = max(拍卖行到手价, NPC 卖店价)：拍卖行无价时直接按卖店价，到手价低于卖店时也按卖店价（列表标「按卖店」）。
- **拍卖行手续费**：成品卖拍卖行时，收入按**到手价**计 —— 成交额扣 5% 手续费
    
  （`到手 = 成交 − floor(成交 × 5%)`）。所以「材料价 = 成品价」的配方其实是**亏 5%**，
    
  计算结果里的「花费」已经包含这部分；卖店 / 自用不计手续费。
    
  费率可用 `WOWFC_AH_CUT_RATE` 覆盖（0 = 按不扣手续费的旧口径），
    
  结果页会恒定显示一行口径说明，不随操作出现/消失。
- **NPC 限量材料**：草药类（`Item.type = Herb`，如地根草/跌打草/皇血草）等 NPC 只少量售卖的材料，
    
  冲级不能依靠 NPC 存量，**只按拍卖行计价**；材料清单与配方行标注「NPC限量」。
    
  若私服还有其他限量货，在 `backend/app/services/calc.py` 的 `MANUAL_LIMITED_ITEM_IDS` 里按物品 ID 追加即可。
- **设计图成本**：`AH 购买计入` 模式下，路线中每个设计图配方首次使用时将其图纸价作为一次性成本计入
    
  （材料清单中以「设计图」标出，数量恒为 1）；`掉落不计` 模式不计价。
- **确认次数**：确认采用的配方可填制作次数（默认 1）。长 CD 配方（如按天才做一次的转化）
    
  按一个查询周期内实际可做次数填写；次数用尽后该配方退出路线（未参与计算列表标注「确认次数已用完」）。
- 中位数口径下取该物品在本服务器的全部导入记录的中位数（可在配置中加时间窗）。

## API 摘要（/api/v1）

| 方法       | 路径                                                             | 说明                           |
| -------- | -------------------------------------------------------------- | ---------------------------- |
| GET/POST | `/servers`                                                     | 服务器列表 / 新建（同名幂等）             |
| GET      | `/professions` `/professions/{key}/recipes`                    | 专业列表 / 配方（可带价格）              |

| POST     | `/prices/manual`                                               | 单物品手动录价                      |

| POST     | `/routes/calc`                                                 | 计算路线（屏蔽/确认/图纸成本参数见 `CalcIn`） |
| POST/GET | `/routes` `/routes/{share_code}` `/routes/{share_code}/recalc` | 保存 / 列表 / 详情 / 采用重算          |

## 图标（物品 / 专业 / 金钱）

- **物品图标**来自无限官方数据库（`/tubiao/<图标名>.jpg`，`inv_ingot_02` / `spell_xxx`
    
  命名与原版同一套体系，无限新增物品原版 wowhead 反而没有），由 `scrape_icons.py`
    
  从官方开放 API 详情接口抓取并随种子入库。前端引用官方 CDN，加载失败自动回退
    
  原版 wowhead 图标 CDN（`wow.zamimg.com`，同一命名）。
- **专业图标**用官方库同一套 WoW 图标名（`trade_blacksmithing`、`trade_engraving`、
    
  `inv_misc_food_15`（烹饪）、`inv_misc_bandage_15`（急救）等），映射见 `app/seed.py`
    
  的 `PROFESSION_ICONS`，随种子写入 professions.icon。
- **金钱**以金币/银币/铜币 **矢量 SVG** 图标 + 数字展示（前端 `components/Money.vue`），零值单位省略。
    
  游戏原生贴图只有 16×16（`UI-GoldIcon` / `UI-SilverIcon` / `UI-CopperIcon`），缩到 13px 会发糊，
    
  所以按原生配色（金 `#d8c14d` / 银 `#9a999a` / 铜 `#ac714c`）重绘为矢量，任意 DPI 都锐利且零请求。

## 物品悬停信息卡（仿游戏内 tooltip）

鼠标停在**物品图标或物品名称**上 250ms 弹出（`ItemIcon` 的默认插槽里放文字即可，
`.ic-hover` 整块都是悬停区，文字悬停时出现虚线下划线提示），版式照搬游戏：名称（品质色）→ 物品等级 / 物品 ID →
  
绑定 / 部位（右对齐护甲类型）/ 护甲值 / 属性 / 耐久 / 需要等级 / **绿色装备特效** / 售价（带硬币图标），
  
底部另起一行给本服拍卖行参考价 + 这条价多久前导的（游戏里看不到、冲级要用），过期再加一行红字提示。

数据不是我们拼的：来源是官方开放 API `GET /items/{id}` 的 `tooltip` 字段——就是游戏里那一整块文本的逐行数组，
  
`\t` 天然表示「部位 / 护甲类型」两栏。抓取脚本 `scraper/scrape_tooltips.py`（限流 5 次/秒，约 15 分钟，
  
支持断点续传）落 `data/item_tooltips.json`，再由 `python -m app.seed --tooltips-only`
  
写进 `items.tooltip`（JSON 字符串数组），接口 `/items/{id}` 以 `tooltip: string[]` 返回。

## 已知边界 / 后续路线

- 暂无账号体系，服务器/路线按昵称署名，分享码即权限；
- 「野营」专业的营地物件配方暂未收录（官方页无配方表）。
