### 2. 云价格有效期（用户问「有效期在哪显示」→ 之前**根本没显示**）

  `calc.price_age_hours()` 统一算年龄。

  新接口 `GET /prices/freshness?server_id=` → `PriceFreshnessOut`（last_import_at、age_hours、item_count、
  stale_items、oldest_age_hours、last_imported_by、valid_hours、stale）。
- 前端：计划页参数区下方**恒定一行** `.fresh-row`（含无数据态，防抖动）、导价页 `.fresh-line`、
  物品卡 `.tip-ah` 显示「· 2 天前」+ 过期红字 `.tip-stale`。**只提示不改算法**（老价仍参与计算）。

### 3.「出处：出没」到底是不是掉落
- 结论：**是掉落/开箱类，但只精确到地图**。官方站 `/zhuanye/{slug}` 配方表「来源」列把来源分几档：
  `训练师 / 商人 · NPC · 地图 / 世界掉落 · 怪物 A–B 级 / 掉落 · NPC · 地图 x%（带掉率）/ 任务 · xxx /
  出没 · 地图列表`；`出没` 是**没有具体 NPC、没有掉率**的那一档（常和「开启 瓶中信 / 破损的箱子」同时出现，
  例：结构图：机械松鼠 = 出没·洛克莫丹、贫瘠之地、赤脊山 + 开启 瓶中信）。
- `SourceTip.vue` 重写：`出处：` 一行按 `；` 拆段，`训练师/商人/世界掉落/掉落/任务/出没/开启` 翻成
  「训练师 / 商人出售 / 世界掉落 / 怪物掉落 / 任务奖励 / 出没地图 / 开箱获得」标签 + 一句注解，
  底部 `↳` 只列本浮层用得到的说明。背景不透明度提到 0.985（原来 0.96 会透出表格数字）。
